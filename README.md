# Web Development Bootcamp Portfolio

Hi! I'm David Hu, and I made this repository to showcase my web development journey through **Dr. Angela Yu’s Web Development Bootcamp**—a project-based curriculum from HTML, CSS, JavaScript, jQuery, and React through tooling, Node/Express and databases, deployment, and introductory Web3. One end-to-end web development track.

This was my first entry point into the world of computer science, before I had any academic background or industry experience; when I was naive and thought software engineering was just "coding" (as I write this in 2026, how things have changed!).

Each linked folder has its own README for file-level detail. The blurbs below are the “why open this?” layer; the table after maps syllabus topics to paths.

---

## Module guide

**[`html-portfolio/`](./html-portfolio)** — Single static hub (`index.html`) that routes to the best-looking HTML/CSS deliverables with **screenshots** (fast skim for layout quality). Showcases the Flexbox pricing table, **Mondrian-style pure CSS Grid composition**, TinDog (Bootstrap multi-section landing), flag/meme/agency pieces, etc., without digging through numbered lesson dirs.

**[`Html+CSS/`](./Html+CSS)** — The full static tree: semantic HTML drills with mini-projects like **Motivation Meme**, **CSS Flag** (stacked/positioned blocks), **Web Design Agency** (responsive sections), **Flexbox pricing cards**, **Mondrian grid “painting”**, and **TinDog**. If you care about **layout/positioning/Grid/Flexbox** in isolation for example, this is the meat.

**[`JavaScript/`](./JavaScript)** — Top-level `.js` files are syntax/loop/array/object reps. The **interactive** work is in folders: [`Drum Kit Starting Files`](./JavaScript/Drum%20Kit%20Starting%20Files) (keydown → audio + button state), [`Dicee+Challenge+-+Starting+Files`](./JavaScript/Dicee+Challenge+-+Starting+Files) (two-dice roll, DOM image swap, win logic on refresh), [`DOM Challenge Starting Files`](./JavaScript/DOM%20Challenge%20Starting%20Files) (select/manipulate DOM). That’s where the browser I/O lives.

**[`jQuery/`](./jQuery)** — A scratch **`index.html`** for jQuery API play (events, fades, DOM churn; more functional than pretty). The polished piece is [`Simon Game`](./jQuery/Simon%20Game): which includes growing color/sound sequence, user replay, game-over/restart—**boss-level** for this section.

**[`React/`](./React)** — Vite apps per lesson: JSX → components → props → **`useState`** → conditional render → forms → nested state / spread → **Keeper** thread (`293-keeper-app-*` … `320-styling-the-keeper-app-*`): notes list, add/delete, component tree, then styling pass. **`320-*`** is the most assembled end state.

**[`Git/`](./Git)** — Text notes from the Git/GitHub chapters; no runnable exercises in-repo.
