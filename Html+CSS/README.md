# HTML & CSS (sections 2–11 + Capstone 1)

Hands-on exercises and projects from **Dr. Angela Yu’s** *[The Complete Full-Stack Web Development Bootcamp](https://www.udemy.com/course/the-complete-web-development-bootcamp/)*. This folder is the **full lesson tree** (every numbered exercise); for a **single-page gallery** with screenshots of selected highlights, see [`Html-Portfolio/`](../Html-Portfolio/). Broader bootcamp context: [repo overview](../README.md).

**Contents:** [Competencies](#competencies) · [How folders map to the course](#how-folders-map-to-the-course) · [Run locally](#run-locally) · [Related](#related)

## Competencies


| Area | What’s in here |
|------|----------------|
| **HTML** | Document structure, semantics, lists, links, images, multi-page layout (`4.0`–`4.1+Webpages`), paths |
| **CSS fundamentals** | Selectors, cascade/specificity, box model, color, typography, positioning |
| **Layout** | Floats/display patterns (`8.x`), **Flexbox** (`9.x`, pricing table project), **CSS Grid** (`10.x`, Mondrian) |
| **Responsive UI** | Media queries, fluid layouts, viewport-aware behavior (`8.2`–`8.4`) |
| **Bootstrap** | Grid/components/utilities culminating in a full marketing-style page (**TinDog**, `11.3`) |
| **Capstone** | Multi-section **online resume** in [`Capstone 1`](./Capstone%201) |

Stack throughout: **vanilla HTML5/CSS3** and **Bootstrap 5**.

## Run locally

Static files only: open any folder’s main HTML (usually `index.html`) in a browser, or from a terminal:

```bash
cd "3.4 Birthday Invite Project"
open index.html   # macOS; or double-click the file / use Live Server in your editor
```

No install, bundler, or server required.
